// these two enums is special to the compiler except where they live: this file is the
// module `@core/prelude`, owned by the toolchain rather than by a project, and every
// module imports it implicitly. `docs/spec.md`, *The core prelude*, owns the rules.
//
// `?` recognises `Result` by that identity — this module and this name — and never by
// the shape of its variants, which is why a project may not declare a type of either
// name.

/// The outcome of something that can fail: a value, or a typed error value.
pub enum Result[T, E] {
    Ok(value: T),
    Err(error: E),
}
