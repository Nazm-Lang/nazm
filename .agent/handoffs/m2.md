### Gates

- **Gates that read source by path read whole modules** (`3e76a07`): interpreter boundary, single
  resolver, checker codes, `tests/codes.rs`. **Probes:** a line naming `nazm_syntax` added to
  `eval/task.rs` failed `core ir boundary`; a function added to `check/mod.rs` failed `module
  boundaries`.
- **Module boundaries** (`a737fc7`): a register of the split modules; an entry may define only the
  façade, shared context and orchestration it names (plus `mod`, `use`, impls of those types); every
  file of a split directory opens with a `//!` responsibility line; a registered entry missing from
  the tree fails. Six unit tests break each rule. Not a line-count rule: a legitimate new façade item
  is admitted by naming it in the register, where a reviewer sees it.
- **LIR oracle:** stays an independent implementation of the number rules, recorded in
  `docs/internal/maintainability.md` §3 and §6 as a deliberate cross-check; shared: type inventory, edge
  corpus, vectors.
