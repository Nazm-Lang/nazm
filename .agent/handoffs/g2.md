## Known limitations

As `docs/limitations.md` records, among them: `@deprecated` warns nowhere (one severity); attributes
only before top-level declarations; no signals, TLS, HTTP or DNS beyond `net_resolve`; `--features`
reaches the root only and `default` cannot be switched off; fuzzing is a fixed input sequence; each
test is its own build; the self-hosted compiler does not carry Gate 2. The three Q1 fix-before-v1
items remain carried: an oversized task frame faults on its guard page instead of `N0408`, a small
C-thread export faults instead of `N0408`, and the wasm32 C-ABI handle width.
