# {{name}}

A contract under the `web3` profile. `nazm check .`; `nazm contract src/main.nz` prints its
entrypoints with what each reads and writes; `nazm contract src/main.nz --txs txs.txt` runs the
transactions deterministically; `--evm DIR` writes EVM bytecode and `--wasm DIR` a WebAssembly
module with its host adapter.
