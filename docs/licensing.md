# Licensing — technical audit for 1.0, and the 0.9.0 preview

**Decided 2026-10-11 by the copyright holder: `Apache-2.0 WITH LLVM-exception`, copyright Ferdous
Alam** (`LICENSE`, `NOTICE`). The exceptions — LLVM's and Cranelift's — let a program carry the parts
of Nazm compiled into it (the runtime, the core prelude, the standard library) without complying
with sections 4(a), 4(b) and 4(d): no licence text, notice or attribution travels with what a user
builds. Also decided that day: a contributor licence agreement, MIT-0 for the `nazm init` templates,
CC-BY-4.0 for the specification, and no per-file licence headers. What is still open is under
*What a human must decide*, below.

This page records what a Nazm release and a program it compiles contain, and under which terms
each part reaches its recipient, as facts a person can check. It draws no legal conclusion.
Audited in Gate 1 of the v1 programme, 2026-10-07, at the tree that declares toolchain 1.0.0; the
facts below that the decision changed say so.

## What a compiled program contains

| Part | How it reaches the program | Source |
| --- | --- | --- |
| **The runtime** | LLVM IR text generated by the Rust crate `nazm-runtime` (`core.rs`, `entry.rs`, `os.rs`, `switch.rs`, `board.rs`, `wasm.rs`) and compiled into every native executable by `nazm build`, together with per-target entry and `errno` units; or a prebuilt `libnazmrt.a` from `nazm runtime build`. The Rust crate itself is not linked into user programs | project code, Apache-2.0 |
| **Third-party code in the runtime** | none: `nazm-runtime`'s one dependency, `blake3`, computes the runtime's digest at build time and emits nothing into the IR | — |
| **The core prelude** | `library/core/prelude.nz`, compiled into every program (`include_str!` in the compiler) | project code, Apache-2.0 |
| **The standard library** | each `library/std/*.nz` module a program imports with `use "@std/…"`, compiled into it | project code, Apache-2.0 |
| **Generated glue** | WebAssembly imports, EVM and account-contract scaffolding for the experimental targets; no licence header in any generated output | project code |
| **Project templates** | `nazm init` copies `crates/nazm-cli/templates/{cli,library,server,embedded,wasm,contract}` into the user's directory, with no licence header | project code, MIT-0 (*since 2026-10-11*) |
| **`nazm bindgen` output** | declarations derived from the user's own C header | the user's |

`bin/nazm` statically links about 238 third-party crates. Their licence expressions, read from

licence field):

| Licence expression | Crates |
| --- | --- |

| MIT | 37 |

| Unlicense OR MIT | 7 |
| triple, including Apache-2.0 WITH LLVM-exception | 5 |
| Apache-2.0 only (`esaxx-rs`, `rmcp`, `spm_precompiled`, `tokenizers`) | 4 |
| Apache-2.0 OR MIT OR Zlib | 2 |
| BSD-2-Clause OR Apache-2.0 OR MIT (`zerocopy`) | 2 |
| Zlib (`foldhash`) | 1 |

**Copyleft:** only `r-efi` (5.3.0 and 6.0.0), as `MIT OR Apache-2.0 OR LGPL-2.1-or-later` — one
option of three. No GPL, AGPL or MPL, and no unknown licence. `deny.toml`'s allow-list names
Apache-2.0 (with and without the LLVM exception), MIT, BSD-2/3-Clause, ISC, Unicode-3.0 and Zlib;
Unlicense, BSL-1.0, CC0-1.0 and MIT-0 appear only as alternatives beside one of those. The
tokenizer data `nazm-tokens` records (two MIT, two Apache-2.0) is not embedded in the binary.

## What a release archive contains

`scripts/release-candidate.sh` copies `README.md`, `LICENSE`, `LICENSE-CC-BY-4.0`, `NOTICE`,
`THIRD-PARTY-NOTICES.md` (since the 0.9.0 preview), `SECURITY.md` and `CONTRIBUTING.md` beside
`bin/nazm`, `bin/nazmc-selfhosted`, the documentation, schemas,
examples, the compiler written in Nazm, the benchmark and scripts. `THIRD-PARTY-NOTICES.md` is
generated from `Cargo.lock` by `cargo xtask notices` — the crates `bin/nazm` and `bin/nazm-mcp`
link for `aarch64-apple-darwin`, each with its licence expression, authors and every licence or
notice file it ships — and `cargo xtask check` fails when it falls behind the lockfile. The SBOM
stays in the separate evidence bundle.

## What a human must decide

**Decided (2026-10-11, the copyright holder):**

1. **The runtime and standard library in user programs** — `Apache-2.0 WITH LLVM-exception` for the
   whole project: the compiled runtime, `libnazmrt.a`, the prelude and the standard-library modules
   impose nothing on a compiled program.
2. **The copyright holder** — Ferdous Alam; `NOTICE` carries the line.

3. **Contributor terms** — a contributor licence agreement (`docs/CLA.md`): the contributor keeps
   copyright and licenses the contribution to the copyright holder with the right to relicense it,
   commercially included. Signed through a bot, CLA Assistant Lite (`.github/workflows/cla.yml`),
   which keeps the signatures in this repository; it stays off until the repository variable
   `CLA_ENABLED` is set. The text is a draft written without legal review; it is reviewed by a
   lawyer, and the bot switched on, before the first outside contribution is accepted.
4. **Templates** — MIT-0 (`crates/nazm-cli/templates/LICENSE`).
5. **Headers** — none: no copyright or SPDX line per file; the root licence files govern.
6. **The specification** — CC-BY-4.0, and also the project's licence (`docs/spec.md`, its opening;
   `LICENSE-CC-BY-4.0`). The rest of `docs/` stays under the project's licence only.

7. **Third-party notices** — to be removed at the source: the toolchain is rewritten in Nazm, soon
   rather than after years, so `bin/nazm` stops linking the third-party crates of *What the
   toolchain contains*. The duty does not wait for the rewrite: a toolchain binary published
   before it — a 0.x preview included — links those crates and owes their licence texts and
   notices, which can be generated from `Cargo.lock`. The rewritten toolchain owes none only if
   it links no third-party code; calling a separately installed `clang` (`DRIVER` in
   `crates/nazm-cli/src/backend.rs`) carries no notice, while a backend linked in, as Cranelift is
   today, would. *For the 0.9.0 preview (2026-10-12):* the archive carries
   `THIRD-PARTY-NOTICES.md` (*What a release archive contains*), which discharges the duty for it.

**Still open:**

8. **The name, worldwide.** A licence does not protect "Nazm"; Apache-2.0 section 6 grants no
   trademark rights. A search for existing marks, the route to registration in many countries,
   and a short usage policy are open.
9. **Legal review** of `docs/CLA.md`, after which the bot is switched on.

**Bearing on a toolchain rewritten in Nazm** (decided 2026-10-11 as the project's direction): the
licences above apply to `.nz` source as to Rust; the third-party crates of *What the toolchain
contains* leave the binary as they are replaced, which shrinks item 7; Rust code translated into
Nazm is a derivative work of it, so contributors' rights in the Rust code carry over to the
translation.
