# Nazm 0.9.0 — a public preview of the 1.0 draft

**Toolchain 0.9.0. Language: the 1.0 draft. Target: macOS on Apple Silicon (`aarch64-apple-darwin`)
only.** Released by the copyright holder's decision of 2026-10-12
([`openspec/changes/release-0-9-preview`](../../../openspec/changes/release-0-9-preview/proposal.md)).
This file records what the preview is, what was checked for it and what was not; it is not updated
as the project moves. Current implementation truth is
[`../capability-matrix.md`](../../internal/capability-matrix.md); what is not done is
[`../limitations.md`](../limitations.md).

## What a preview is

- **No compatibility promise until 1.0.** [`../stability.md`](../stability.md) states the contract
  1.0 will make; a 0.x release may still change what it says, and says so in its notes.
- **The toolchain is the Rust implementation.** It is being rewritten in Nazm
  ([`openspec/changes/rewrite-in-nazm`](../../../openspec/changes/rewrite-in-nazm/proposal.md)); 1.0
  comes after that rewrite and its release gate. A second compiler written in Nazm, for a declared
  subset of the language, already compiles itself (`compiler/`, [`../bootstrap.md`](../../internal/bootstrap.md)).
- **One target.** macOS on Apple Silicon. Linux, Windows, Intel Macs, WebAssembly and the embedded
  boards are exercised in this tree (`../support.md`) but are not released: a binary is published
  for `aarch64-apple-darwin` only.
- **External contributions are not accepted yet.** The contributor licence agreement
  ([`../CLA.md`](../../internal/CLA.md)) awaits legal review; issues are welcome.

## Installing

1. Download `nazm-aarch64-apple-darwin.tar.gz` and its `SHA256SUMS`, and check it:
   `shasum -a 256 -c SHA256SUMS`.
2. Unpack it and put `bin/nazm` on your `PATH`.
3. The binary is **ad-hoc signed, not notarized** (no Apple Developer ID). A file downloaded with a
   browser is quarantined, and macOS refuses to open it; clear that once with
   `xattr -d com.apple.quarantine bin/nazm` (or Open from Finder's context menu). A file downloaded
   with `curl` is not quarantined.
4. `nazm build` compiles through `clang` and links with the system linker: install the Xcode Command
   Line Tools (`xcode-select --install`). `nazm run` (the interpreter), `check`, `test`, `fmt`,
   `doc` and the language server need nothing else.

[`../getting-started.md`](../getting-started.md) goes from there to a checked, tested, natively
compiled program in about ten minutes.

## What is in it

The language as [`../spec.md`](../spec.md) settles it: records, enums and patterns, generics,
traits and methods, closures, `Result`/`Option` and `?`, modules and packages, declared effects,
capabilities and provenance, structured concurrency with channels and deadlines, numbers of every
width, arrays, bytes and text, files, networking and processes, and an FFI to C — compiled through
one shared low-level IR to LLVM or Cranelift, or run by the interpreter, with deterministic memory
reclamation and no garbage collector.

**New since the tree's last record, all EXPERIMENTAL** — usable, tested on the interpreter, the LIR
oracle, LLVM `-O0`/`-O2` and Cranelift with every allocation reclaimed, and open to change before
1.0 (`../spec.md`, each section's class):

| Addition | Section |
| --- | --- |
| `for x in xs` and `for i in a..b` | *`for` loops* |
| `Box[T]` and `List[T]` — recursive types through immutable indirection, released without recursion | *Immutable indirection* |
| patterns: `_`, literals, alternatives, nesting, `if let`, `let … else` | *Patterns* |
| tuples, and `let (a, b) = …` | *Tuples* |
| ordering and hashing derived from what a type contains | *Ordering and hashing are derived* |
| arrays of strings, constant tables, `pub const` | *Constant tables and exported constants* |
| multi-line `"""` and raw `r"…"` strings | *Multi-line and raw strings* |
| `f"…{x}…"` interpolation, `float_to_str_fixed`, padding | *String interpolation* |

## What was checked, and what was not

Run on the released source, on macOS 27 on Apple Silicon:

- **The host suite:** 2,791 tests; 2,750 passed, 81 skipped, and 41 refused — the self-hosting
  tests, which run only inside the container and refuse on the host by design. The doc tests,
  `cargo xtask check` (24 checks, the third-party notices among them) and `cargo fmt --check` are
  clean.
- **In the container** (4 GiB, 4 CPUs, a one-hour deadline): the whole test suite passed; the
  self-hosting gate passed 44 of 44; the bootstrap passed — the compiler written in Nazm, built by
  itself, is byte-identical to the build before it, 34 conformance programs and 30 refusals agree
  with the reference, the IR is identical, and the executables are byte-identical once the linker
  UUID is removed.
- **Mutation testing of the R1 additions:** 29 of the 70 mutants written for them have run, and
  every one was caught. The other 41 — most of them for the constant tables, the string literals
  and the interpolation — run after this preview.

The archive's SHA-256 is in `SHA256SUMS` beside it on the release page.

**Not done for this preview, and named so:**

- **The full release mutation catalogue was not run.** It is about 1,700 mutants at several minutes
  each in one container; it stays outstanding for 1.0. 29 of the 70 mutants written for the R1
  additions were run (above).
- **Platforms.** Only macOS on Apple Silicon is released. Real Linux and Windows x86_64 machines,
  and real Windows, remain final-1.0 qualification items; Windows is exercised under Wine only.
- **Signing.** The binary is ad-hoc signed and not notarized.
- **Legal.** The CLA's legal review, and a trademark search and registration, are open.

## History

This is the first public release. The tree said toolchain 1.0.0 from Gate 1 of the v1 programme
until this preview, with no 1.0.0 ever tagged; 0.9 was chosen over 0.3, which an earlier internal
candidate used ([`996984f.md`](../../internal/releases/996984f.md)). Before the repository was made public, two folders of
working prompts committed by mistake were removed from its history, which changed the hashes of the
commits after them; the hashes the documents cite were updated with them.
