## What this release is

0.10.0 made the language ready to write its own toolchain. 0.11.0 is that toolchain: the compiler,
the interpreter, the commands, the test harness and the tests are written in Nazm, and the `nazm` you
download is built by Nazm from Nazm. The Rust implementation that came before it is frozen as the
bootstrap seed — the program that builds the first Nazm-written compiler — and changes only by a
recorded decision of the copyright holder (`docs/internal/seed-freeze.txt`).

As for 0.9.0 and 0.10.0: no compatibility promise until 1.0, and external contributions are not
accepted yet. Language changes since 0.10.0 are in [`../spec.md`](../spec.md); a program that built
with 0.10.0 builds with 0.11.0 unless a changed rule named there says otherwise.
Four changed rules can break a 0.10.0 program:

- `List[T]` is now the growable list; the immutable sequence is `Chain[T]`, and the `list_from_vec`,
  `list_empty`, `list_len` and `list_get` built-ins are now `chain_*` (a missing `list_*` built-in is
  N0637, naming its replacement).
- `[1, 2, 3]` with no `[T; n]` expected type is a shared growable list, not a fixed array: write
  `let a: [Int; 3] = [1, 2, 3]` for an array. An untyped empty `[]` is N0618.
- A pattern `let` binds in the scope it is written in, so rebinding a name in the same block is N0202.
- `nazm run` compiles natively; `nazm run --interpret` is the interpreter, and `--max-iterations`
  and `--max-depth` need `--interpret`.

Linux, WebAssembly, WASI, Android, iOS and the boards are refused by name by `nazm build` in this
release (they return in 0.12.0 and 1.0), and `--backend cranelift` is refused, naming `llvm` and `nazm`.

## Installing

Download the archive for your machine and `SHA256SUMS` from the release page, check, unpack, and put
`bin/nazm` on `PATH`:

| Machine | Archive |
| --- | --- |
| Apple Silicon Mac | `nazm-aarch64-apple-darwin.tar.gz` |
| Intel Mac | `nazm-x86_64-apple-darwin.tar.gz` |

On a Mac the binary is ad-hoc signed and not notarized: clear the quarantine flag once. `nazm build`
needs the Xcode Command Line Tools on a Mac. Homebrew: `brew install nazm-lang/tap/nazm`.

## What is in it

| Area | What |
| --- | --- |
| The toolchain in Nazm | The lexer, parser and checker agree with the Rust reference on every input they carry; the intermediate representations, ownership and cleanup, the runtime's units and the object cache are identical to the reference's on both Mac targets; the interpreter and every command are ported and compared against the reference |
| Nazm's own code generator | `nazm build --backend nazm` writes Mach-O objects for both Mac targets, checked against LLVM program by program; LLVM stays the default and Cranelift stays available |
| Self-hosting | The compiler built by itself is byte-identical to the build before it (stages 1 to 3), and the self-built interpreter and checker agree with the seed's on the corpus; the build holds a bounded heap |
| A host rule | One Nazm-built program may run on the macOS host, under a counted 2 GiB heap, one at a time and never beside a container; everything else Nazm builds runs only in the container (`xtask host-run`) |
| Windows | Not in this release: it moved to 0.12.0 (decisions log, 2026-11-14). The earlier Windows host runs (70 programs agreed, 0 differed; toolchain 94 agreed, 2 differed on the httpd baseline) are history, not a claim about 0.11.0 |

## What the gate found and fixed

The gate is run to find things. Between 0.10.0 and this release it found, and the release fixes:

- **A recursion that never ended.** A user type that referred to itself made `UserTypes::depth` loop
  (the seed-freeze exemption for it was approved by the copyright holder). The check now stops at a
  cycle and reports it.
- **A fuzz run that could hang unseen.** The fuzz harness gained a watchdog that kills a stuck
  target and reports it.
- **A test that did not test.** The mutation campaign let one mutant survive — the Cranelift
  backend's version string leaving out its optimisation level, so an object built at one level could
  be reused at another. The test compared cache keys that differed for another reason, so it passed.
  It now checks the version string itself, and fails on the mutant. Four more tests were
  strengthened for mutants whose killer passed on the mutant (the registry republish, equality of
  handle sequences, the stdlib module lookup, the order of a native comparison's operands).
- **Windows and arm CI.** Ten tests that need a Unix host are compiled only on Unix; one lock test
  that raced a forking neighbour waits the race out.

## What was checked, and what was not

Run on macOS 27 on Apple Silicon, on `TODO(gate): the commit the archives were built from`.

- **The host suite** (`cargo nextest run --workspace`): 3,136 passed, 85 skipped, 41 refused. The
  self-hosting tests refuse on the host by design and run in the container.
- **In the container** (4 GiB, 4 CPUs): the whole test suite, the self-hosting gate, the bootstrap
  and the self-build all passed. On the bumped commit: 3,130 tests passed, 0 failed; selfhost, bootstrap and self-build agree.
- **Fuzzing:** five targets, 600 s each, 5,116,989 executions, 0 crashes, 0 out-of-memory. The `run`
  target reports programs that block on purpose (waiting for input that never comes) as hangs; they
  are the target's design, not defects.
- **Mutation testing: the full targeted campaign, 2,113 mutants,** run in the container. 2,081 were
  decided by the fast tier and the remaining 32, which need the whole baseline suite, in a second run
  with a longer deadline. 0 survivors at the end (the one that survived once is named above). No mutant was dropped or excepted and no test was weakened.
- **Windows:** not run for this release, which ships for macOS only.
- **Benchmarks:** no regression against `bench/baseline`, run last and alone in a quiet window:
  `TODO(gate)`.
- **Reproducible build:** the archives are built twice and compared: `TODO(gate)`.

The archives' SHA-256 are in `SHA256SUMS` beside them on the release page.

**Not done for this release, and named so:**

- **The full mutation strategy** (`--strategy full`) is infeasible at this size; the targeted
  campaign above is the release's mutation evidence.
- **Platforms.** Linux, wasm32 and WASI are planned for the next release; this one ships the two
  macOS targets above. Windows x86_64 moved to 0.12.0.
- **Signing.** Binaries are ad-hoc signed and not notarized.
- **Legal.** The CLA's legal review and a trademark search are open.
